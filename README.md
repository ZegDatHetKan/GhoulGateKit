# GhoulGate Kit

Reusable production kit for pixel‑anime videos with the **Based Ghoul** characters: soundtrack, character model sheets, monsters,
voices, sprites, fonts and the Python engine that generates them. No episodes or storylines — only the infrastructure.

| Folder | Contents |
|---|---|
| `music/` | 35 original cues (MP3 320k): opening, ending, recap, eyecatch, stingers and scene moods — see `music/TRACKLIST.md` |
| `character_sheets/` | One model sheet per ghoul (PFP, native sprite, full body, 12 expressions, 12 poses), cast lineup, monsters, console, BTC Demon, props |
| `assets/ghouls/` | Original PFPs, named by character key |
| `assets/monsters/` | 19 original monster images |
| `assets/sprites/` | Processed native‑resolution sprites (ghouls, monsters, monsters_hd, props) |
| `assets/props/` | Lila flame, GHOULIPS drink icon · `assets/logo/` the Crypt logo · `assets/fonts/` subtitle/SFX/UI fonts (SIL OFL) |
| `voices/` | `VOICE_CAST.md` (VOICEVOX speaker + style per character and emotion) and `samples/` — one line per character and style (`SAMPLES.md`) |
| `engine/` | The Python pipeline: sprites, faces/poses (`face.py`), worlds, the BTC Demon, music synthesis (`music.py`), voices (`voice.py`), OP/ED, renderer |

## Regenerating
```bash
engine/setup.sh                                         # creates engine/.venv
engine/.venv/bin/python engine/export_music.py music    # rebuild the soundtrack
engine/.venv/bin/python engine/make_sheets.py           # rebuild the model sheets
```
The engine expects the project layout of the original workspace (`assets/originals/…`, `tools/` with the VOICEVOX engine and a
General MIDI soundfont, which are not included here because of their size — `engine/setup.sh` and `engine/paths.py` show where they go).
